# Event Management System – Project Planning & Requirement Analysis

## 1. Project Title

Event Management System

## 2. Problem Statement

Managing events manually can make it difficult to organize event details, participants, schedules, and registrations.

## 3. Objective

To develop a web-based system that helps users create, manage, and organize events efficiently.

## 4. Target Users

* Administrator
* Event Organizer
* Participant

## 5. Core Modules

* User Management
* Event Management
* Registration Management
* Schedule Management
* Dashboard and Reports

## 6. Project Scope

### Included

* User login
* Create and manage events
* Participant registration
* Event schedules
* Dashboard and basic reports

### Excluded

* Mobile application
* Online payment
* Live chat
* AI features

## 7. Functional Requirements

* Users can register and log in.
* Organizers can create, update, and delete events.
* Participants can register for events.
* The system stores event details and schedules.
* Administrators can manage users and events.

## 8. Non-Functional Requirements

* Security
* Performance
* Usability
* Reliability
* Maintainability

## 9. Expected Outcome

The Event Management System will provide a centralized platform for organizing events, managing registrations, and reducing manual work.
